## 🚀 Proyek Utama & Portofolio

### 1. [sangavril.web.id](https://sangavril.web.id) (v10.5.1 Final)
- Situs portofolio personal bilingual (ID/EN) yang dibangun dengan **React 19 + TypeScript + Vite 7 + Tailwind CSS**.
- Dioptimalkan untuk SEO (Sitemap XML, Open Graph, JSON-LD), aksesibilitas WCAG, serta di-deploy secara otomatis di Vercel Production.

### 2. Sistem Pencarian & Manajemen Surat Jalan (Item Finder v2.5)
- Aplikasi desktop berbasis **Python (Tkinter & openpyxl)** untuk pemindaian otomatis dan ekstraksi data dari ribuan baris berkas Excel Surat Jalan ekspedisi secara instan.

### 3. ECU Simulator — Sangavril Edition (Firmware v15.2.1)
- *Hardware simulator* Engine Control Unit berbasis **Arduino Nano (ATmega328P)** dengan skrip C/C++ kustom dan antarmuka *dashboard GUI real-time* berbasis Python. Eksplorasi protokol diagnostik otomotif UDS (ISO 14229).

### 4. Sangavril Optimizer (Magisk Module v3.0 Final)
- Modul optimasi sistem Android khusus chipset **Snapdragon 732G**. Mengimplementasikan *kernel tweaking*, pengaturan kemacetan BBR TCP (*low latency gaming*), serta *buffer tuning*.

### 5. Bengkel Levi Website
- Aplikasi web modern untuk bengkel otomotif dengan fitur *online service booking*, estimasi biaya, dan integrasi WhatsApp terformat otomatis (**React + TypeScript + Tailwind CSS**).
